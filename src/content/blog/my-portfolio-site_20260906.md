## Why I Built This Project

I built this portfolio to create a personal space where I can share my ideas, interests, and projects. It also gives me a place to practice coding, experiment with design, and document my progress as I continue learning. As I gain more experience, I can use this site to show how my skills and projects develop over time.

<!-- more -->

## Description

My personal portfolio shows my ideas, interests, and projects. I started with an Astro theme and changed the design to make the portfolio my own. I used coding to customize the template, add my information, and present my projects in a way that reflects me.

I also used ChatGPT to help me understand coding concepts and fix problems while working on the portfolio. After completing the site, I published it with GitHub Pages so people can view it online. As I learn more about coding, I can continue improving the portfolio and adding new projects.

## Features

The portfolio includes many useful features:

- A home page that introduces the portfolio
- A blog page for sharing posts and ideas
- A tags page that helps organize related posts
- An about page with more information about me
- A simple layout that makes the site easy to explore
- A structure that helps me organize projects and other content

Each page has a different purpose and helps visitors find information easily. Together, these features make the portfolio a useful place to organize and share my work.

## Challenges

One challenge was working with the free version of ChatGPT. Because I did not have access to more advanced coding help, I could not always implement advanced features easily. This resulted in a few flaws in the project and caused some delays while I was working on it.

Even with these challenges, the experience helped me learn more about coding, understand how an Astro project is organized, and become more comfortable solving problems. I can continue improving the portfolio as my skills grow.
